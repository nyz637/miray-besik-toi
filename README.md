# Мирайдың бесік тойы

## GitHub Pages

Репозиторий: https://github.com/nyz637/miray-besik-toi

Адрес после публикации: https://nyz637.github.io/miray-besik-toi/

В Settings → Pages → Build and deployment выберите Source: GitHub Actions. Workflow `.github/workflows/deploy.yml` выполняет `npm ci`, `npm run build` и публикует `dist` при push в `main`; доступен также ручной запуск из Actions. В `vite.config.js` задан base `/miray-besik-toi/`. Музыка из public использует `import.meta.env.BASE_URL`; будущие ресурсы из public подключайте таким же способом, а файлы из src — через import. Не добавляйте dist или node_modules в Git.

Отдельный локальный проект React + Vite. Внешние изображения, шрифты и тяжёлые библиотеки не используются. Существующие проекты и репозитории не изменяются.

## Запуск

```sh
npm install
npm run dev
```

В PowerShell с запретом скриптов используйте `npm.cmd install`, `npm.cmd run dev`.

Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## Данные события

Измените `src/config/event.js`:

- `date`: ISO 8601 с часовым поясом, формат `YYYY-MM-DDTHH:mm:ss+05:00`. При корректной дате появляются дата и обратный отсчёт. Дата отображается по времени Казахстана.
- `time`: время для отображения, например `18:00`.
- `venue`: название заведения.
- `address`: полный адрес. Кнопка 2GIS появляется только с адресом.
- `twoGisUrl`: необязательная прямая HTTPS-ссылка 2GIS. Без неё используется поиск по адресу.

## Музыка

Добавьте собственный файл `public/music.mp3`. Папка public уже подготовлена. Файл должен возвращаться сервером с типом audio/mpeg. Без файла кнопка музыки скрыта. Запуск происходит по нажатию на открытие приглашения; ограничения браузера обрабатываются без ошибки интерфейса. При необходимости включите музыку отдельной кнопкой.

## RSVP и Google Forms

Поля подготовлены, но ответы сейчас не отправляются и не сохраняются. Кнопки отправки нет до подключения `event.onRsvp`.

Самый простой способ подключения Google Forms: создать форму с полями имени, участия и пожелания и добавить реальную ссылку на неё в компонент Rsvp. Для отправки прямо из дизайна сайта нужен серверный обработчик: подключите к Google Forms / Google Sheets Apps Script или собственный API, настройте CORS, валидацию и защиту от спама. Установите `onRsvp: async ({ name, attendance, wish }) => { ... }` в конфигурации. Обработчик обязан возвращать Promise, отклонять его при ошибке и завершать успешно только после подтверждённого сохранения. Не используйте `no-cors` как подтверждение успеха: он не позволяет проверить ответ сервера. Ключи и секреты храните на сервере.
